# 🚀 Primeiros Passos com Blazor Hybrid

Projeto educacional desenvolvido para introduzir os principais conceitos do **Blazor Hybrid com C#** de forma simples, prática e progressiva.

## 📚 Conteúdos trabalhados

* Páginas Razor
* HTML básico
* Bootstrap
* `@bind`
* `@onclick`
* Métodos em C#
* `if` e `else`
* Navegação entre páginas
* Classes e objetos
* Cadastro de clientes
* Integração com MySQL
* `INSERT` e `SELECT`
* Listagem de dados

## 🛠️ Tecnologias

* C#
* Blazor Hybrid
* .NET
* Razor
* Bootstrap
* MySQL

## 🎯 Objetivo

Apresentar os primeiros conceitos de desenvolvimento de aplicações com Blazor Hybrid, relacionando front-end, lógica em C# e banco de dados em exemplos simples e didáticos.

## 📌 Projeto de estudo

Este repositório será atualizado conforme novos conteúdos forem desenvolvidos durante as aulas.
